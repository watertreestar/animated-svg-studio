# 中文主题示例

中文 SVG 示例按主题分目录保存。每套主题都有三种相同布局，方便只比较字体和配色：

| 目录 | 主题 |
|---|---|
| `default-theme/` | 暖色编辑（默认） |
| `ink-paper/` | 水墨纸张 |
| `clear-tech/` | 清透科技 |
| `dark-terminal/` | 暗色终端 |
| `fresh-green/` | 自然生长 |
| `bold-signal/` | 强信号 |
| `crimson-conference/` | 暗红大会 |
| `orange-blue-architecture/` | 橙蓝架构 |

每个目录包含：

- `智能体双层架构.svg`
- `文档审批流程.svg`
- `任务执行状态.svg`
- `index.html`

打开根目录的 `index.html` 可浏览全部主题和示例。

这些示例都是原创、可编辑且不依赖远程资源的 SVG/SMIL 文件。
